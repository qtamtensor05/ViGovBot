# Bố cục mã nguồn

Mã nguồn được triển khai trong package duy nhất [vigovbot](vigovbot/).
Cài package bằng `python -m pip install -e ".[rag,evaluation]"`, sau đó dùng
namespace `vigovbot.*` và CLI `python -m vigovbot`.
